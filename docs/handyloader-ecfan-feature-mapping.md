## 1. 전제 조건 (먼저 확정 필요)

| # | 항목 | 내용 |
|---|---|---|
| 1 | 통신 방식 | FanCM은 RS-485 Modbus RTU 마스터다. 핸디로더도 같은 방식으로 드라이브에 붙는다고 가정한다. (기본 19200bps / 8-E-1, 0xD149·0xD14A로 변경 가능) |
| 2 | 마스터 배타성 | RS-485 버스에는 마스터가 하나여야 한다. PC(FanCM)와 핸디로더를 동시에 연결하면 충돌하므로, 핸디로더 연결 시 PC 분리를 전제로 하거나 드라이브 측에 별도 포트가 필요하다. |
| 3 | Setpoint 제어 조건 | 핸디로더에서 속도를 바꾸려면 Set value source(0xD101)가 **1: RS485**여야 한다. AIN1/AIN2/PWM 현장에서는 핸디로더가 "모니터 + 파라미터 편집기" 역할만 한다. |
| 4 | FC 0x2B 필요 | Motor ID, 시리얼, 펌웨어 버전, 알람 코드(0x603F), 공장 초기화(0x1011) 등 LSM 전용 항목은 전부 FC 0x2B(CANopen SDO over Modbus)로 접근한다. 핸디로더 펌웨어에 FC03/04/06/10 외에 FC 0x2B 구현이 필요하다. |
| 5 | Setpoint 스케일 | Speed 모드(0xD106=0): `raw = rpm / maxSpeed × 64000` (maxSpeed = 0xD119, 현재 FanCM은 1600 RPM 하드코딩). Open-loop(0xD106=2): `raw = % / 100 × 65535`. 핸디로더도 동일 변환을 써야 표시값이 FanCM과 일치한다. |
| 6 | 자체 확장 레지스터 | 알람 리셋 0x800E, 소프트웨어 리셋 0x8001, 모터 전류 0xD052, 지령 속도/토크 0xD050/0xD051은 ebm-papst 스펙 외 자체 확장이다. 핸디로더 사양서에 그대로 옮길 때 펌웨어 팀과 주소를 재확인해야 한다. |

## 2. FanCM 사용자 기능 전수 목록과 핸디로더 적합성

## 3. 핸디로더 21키 매핑 제안

키 이름은 서보 핸디로더 각인 그대로이므로, ECFAN 용도로는 아래처럼 재정의한다. 각인을 바꿀 수 없다면 라벨 스티커 또는 매뉴얼 표기로 대응한다.

| 키 | ECFAN 기능 | 대응 FanCM 동작 |
|---|---|---|
| POSITION RUN | **RUN / STOP 토글**. 정지 중 누르면 현재 Setpoint로 운전, 운전 중 누르면 Setpoint 0 | 카드 Setpoint 적용 / 정지 |
| SELECT / DATA | 주소 입력 ↔ 값 입력 모드 전환, 메뉴 항목 진입 | Parameters 탭 주소·값 필드 |
| HOME | 초기 모니터 화면(실제 속도 + 상태)으로 복귀 | Dashboard |
| ESC | 취소 / 상위 메뉴 | 모달 닫기 |
| RESET | **알람 리셋** (0x800E ← 1). SHIFT + RESET = 소프트웨어 리셋(0xD000 ← 8, 확인 요구) | 카드 🔔 / ↺ 버튼 |
| FIND ADJUST | ECFAN에 직접 대응 기능 없음. 후보: (a) 파라미터 주소 검색 점프, (b) RPM ↔ % 모드 전환, (c) 비밀번호 보호된 Auto Calibration 진입 | (b)는 카드 RPM/% 버튼, (c)는 Manufacture 탭 |
| 0 ~ 9 | 숫자 입력 (Setpoint, 파라미터 값, 주소) | 입력 필드 |
| SHIFT + 4~9 | A ~ F 입력 (hex 주소, 예: D001, 603F) | Manual Input HEX 입력 |
| SHIFT | 보조 키. SHIFT + RESET, SHIFT + UP/DOWN(큰 스텝), SHIFT + WRITE(EEPROM 관련은 미채택) | — |
| UP / DOWN | 메뉴 이동, 값 증감. 모니터 화면에서는 Setpoint 스텝 증감(예: 최대속도의 5 %) | 프리셋 25/50/75 버튼의 연속형 대체 |
| HANDY ↔ DRIVE | **파라미터 세트 복사**. DRIVE→HANDY: 위 2-2 설정값을 핸디로더 메모리에 저장. HANDY→DRIVE: 동일 설정을 다른 드라이브에 일괄 기록 | CSV export / import, Read All |
| WRITE | 입력값 확정 및 FC06 쓰기 | 각 필드의 쓰기 버튼 |

## 4. 권장 메뉴 트리 (7-seg 또는 소형 LCD 기준)

```
[MON]  실제속도(0xD02D) · 상태(0xD011) · 알람코드(0x603F) · 경고(0xD012)
       DC-link V(0xD013) · 모듈온도(0xD015) · 전류(0xD052) · 지령속도(0xD050)
[RUN]  Setpoint 입력 · RUN/STOP · 모드(RPM/%) 표시
[PAR]  모터제어(0xD106/0xD101/0xD102/0xD119/0xD11F/0xD120)
       보호(0xD13B/0xD137/0xD138) · 통신(0xD100/0xD149/0xD14A/0xD1FF)
       센서(0xD147/0xD160/0xD162/0xD12A~D) · 직접주소(H/I + hex)
[ALM]  현재 알람코드 · RESET
[INF]  시리얼 · MCU/INV FW 버전 · Motor ID · HW rev · 전압 클래스
[SYS]  HANDY↔DRIVE 복사 · 소프트웨어 리셋
[HID]  히든 메뉴 (비밀번호 진입): Motor ID 변경 · 전압 클래스 · 서보 튜닝 · 공장 초기화 · (검토: 알람 마스크, Auto Calibration)
```

히든 메뉴 진입 방식 제안: [SYS] 화면에서 SHIFT + SELECT/DATA 길게 누름 → 비밀번호 4자리 입력. FanCM의 Auto Calibration 탭과 동일하게 비밀번호 보호를 두고, 진입 후 일정 시간 무입력 시 자동 이탈한다.

## 6. FanCM에도 없어서 추가 확인이 필요한 항목

핸디로더 요구사항으로 나올 법하지만 FanCM에도 아직 구현되지 않은 것들이다. 넣으려면 드라이브 펌웨어 확인이 먼저다.

| 항목 | 레지스터 | 상태 |
|---|---|---|
| 알람 이력 (최근 13개 + 시각) | 0xD184 ~ 0xD19F | FanCM 미구현 (parameters.csv N). 핸디로더 [ALM] 메뉴에 자연스러운 기능이라 펌웨어 지원 여부 확인 권장 |
| 운전 시간 카운터 | 0xD009 / 0xD00A | 미구현 |
| Enable / Disable | 0xD00F | 미구현. RUN/STOP을 Setpoint 0 대신 이 레지스터로 구현할지 결정 필요 |
| 저장 Setpoint (전원 복구 후 재시작값) | 0xD00D | 미구현 |
| 최소 RPM | — | 피드백(todo list)에서 요청됐으나 레지스터 미정 |
| 드라이브 7-seg 표시 데이터 | 0x2617 (FC 0x2B, ASCII 7자) | 정의만 존재. 핸디로더가 이 값을 그대로 미러링하면 표시 로직을 드라이브 쪽에 둘 수 있음 |
